So funktioniert es
  1. Gruppe erstellen und Code direkt an alle schicken. Wer den Code hat, sieht die Gruppe.
  2. Jeder tippt seinen Namen und den Code ein. Kein Konto, kein Server.
  3. Standort freigeben. Alle sehen sich verschlüsselt auf der Karte, auf Wunsch nur bis zu einer Uhrzeit.
  4. Verloren? "Finde mich!" drücken. Alle bekommen Alarm, in der Android-App auch im Hintergrund.

    Datenschutz

    Der Gruppencode ist der Schlüssel. Wer ihn hat, kann die Standorte der Gruppe sehen, solange ihr diesen Code nutzt, auch nach dem Verlassen. Gib ihn nur direkt an Leute weiter, die dich sehen dürfen. Ist er in falsche Hände geraten, erzeugt ihr im Menü eine "Neue Gruppe mit neuem Code".

    Find Mein Soon hat keinen eigenen Server. Die Handys deiner Gruppe tauschen ihre Daten über einen öffentlichen Nachrichtendienst (MQTT-Broker) aus. Alles wird vorher auf dem Handy verschlüsselt (AES-256, Schlüssel aus dem Gruppencode). Der Dienst sieht deine IP-Adresse, eine zufällige Gruppen- und Mitgliedskennung und verschlüsselte Daten, aber weder Namen noch Standorte noch den Code. Bei ihm bleibt nur der letzte Stand jedes Mitglieds gespeichert und verfällt nach einer Woche; mit "Gruppe verlassen" wird dein Eintrag sofort ersetzt.

    Karten werden von OpenStreetMap geladen. Dabei erhält OpenStreetMap deine IP-Adresse und den Kartenausschnitt. Es gibt kein Konto, keine Werbung und kein Tracking durch Dritte. Gruppen mit altem 8-stelligem Code sind schwächer geschützt; erstellt für sie eine neue Gruppe.

Erstelle eine Gruppe, teile den Code mit deiner Familie oder deinen Freunden und seht euch live auf der Karte.

Als App installieren

Lege Find Mein Soon auf deinen Startbildschirm, dann startet es wie eine richtige App.

Android-App (APK)

Für Android gibt es Find Mein Soon auch als APK-Datei. Herunterladen, öffnen und die Installation aus unbekannten Quellen erlauben.

So funktioniert es
  1. Gruppe erstellen und Code an alle schicken.
  2. Jeder tippt seinen Namen und den Code ein. Kein Konto, kein Server.
  3. Standort freigeben. Alle sehen sich verschlüsselt auf der Karte.
  4. Verloren? "Finde mich!" drücken. Alle bekommen Alarm, in der Android-App auch im Hintergrund.

    Datenschutz

    Find Mein Soon hat keinen eigenen Server. Die Handys deiner Gruppe tauschen ihre Standorte über einen öffentlichen Nachrichtendienst (MQTT-Broker) aus. Alle Daten werden vorher auf dem Handy mit einem Schlüssel aus dem Gruppencode verschlüsselt. Der Dienst sieht nur unlesbare Daten; entschlüsseln kann nur, wer den Gruppencode kennt. Gib den Code deshalb nur an Leute weiter, die dich sehen dürfen.

    Karten werden von OpenStreetMap geladen. Dabei erhält OpenStreetMap deine IP-Adresse und den Kartenausschnitt.

    Beim Nachrichtendienst bleibt nur der letzte Stand jedes Mitglieds gespeichert. Mit "Gruppe verlassen" wird dein Eintrag dort gelöscht. Es gibt kein Konto, keine Werbung und kein Tracking durch Dritte.

Find Mein Soon

Erstelle eine Gruppe, teile den Code mit deiner Familie oder deinen Freunden und seht euch live auf der Karte.

Als App installieren

Lege Find Mein Soon auf deinen Startbildschirm, dann startet es wie eine richtige App.

So funktioniert es
  1. Gruppe erstellen und Code an alle schicken.
  2. Jeder tippt seinen Namen und den Code ein.
  3. Standort freigeben. Alle sehen sich auf der Karte.
  4. Verloren? "Finde mich!" druecken. Alle bekommen Alarm.
Jemand braucht Hilfe

Karte konnte nicht geladen werden. Die Liste unten funktioniert trotzdem.

    Datenschutz

    Dein Standort wird nur an den Find-Mein-Soon-Server dieser Website gesendet und nur den Mitgliedern deiner Gruppe angezeigt. Es gibt kein Konto, keine Werbung und kein Tracking durch Dritte.

    Karten werden von OpenStreetMap geladen. Dabei erhaelt OpenStreetMap deine IP-Adresse und den Kartenausschnitt.

    Gruppen ohne Aktivitaet werden nach 30 Tagen automatisch geloescht. Mit "Gruppe verlassen" wird dein Eintrag sofort entfernt.
